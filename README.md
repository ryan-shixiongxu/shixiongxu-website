# Shixiong Xu website — clean URLs

This site uses three static pages:

- `/` — Home (`index.html`)
- `/cv/` — CV (`cv/index.html`)
- `/research/` — Research (`research/index.html`)

Upload the **contents** of this folder to the root of the existing GitHub repository. Preserve `CNAME`, `styles.css`, `script.js`, and `sequoia-home.jpg` at the root. Upload `cv/index.html` and `research/index.html` in their respective folders. Do not upload the outer folder as a single nested folder. The old research workflow and papers files can be removed separately.

GitHub Pages serves each directory's index.html when the matching URL ends in `/`.
